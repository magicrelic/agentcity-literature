Li et al. - Adaptive capacity for multimodal transport network resilience to extreme floods

极端洪水下，改变出行路线与交通方式如何维持城市交通功能，又为何可能加剧拥堵

一、研究问题

洪水封闭一批道路后，城市还能完成多少出行，不能只看剩下多少道路。乘客可能绕路、改乘公共交通，也可能因公交停运转向小汽车；这些选择又会改变剩余道路的拥堵。因此，基础设施仍然连通、个人找到了替代方案、全城维持了出行能力，是三个不同的问题。

这项研究把洪水造成的网络失效与个体出行仿真连接起来，在南京、汉堡和洛杉矶比较两种适应行为：同一大类交通方式内的路线调整，以及小汽车与公共交通之间的方式转换。其关键发现具有条件性：可用替代路线和方式确实能够挽救出行，但个人趋利的调整不保证改善集体结果。南京部分情景中的公共交通转小汽车，反而使道路更加拥堵；另一些情景则主要依靠公共交通或绕路维持功能（补充 Note 11、补图25–30）。

图1把问题缩成一次通勤。原公交线路的末端节点被淹，即使乘客原本不去该节点，也可能因整条线路失效而受影响；他先改走“地铁—步行换乘—公交”，再在公共交通继续受损时改开车，最后因唯一通路被切断而无法出行。这里公交与地铁之间的组合调整归入公共交通内部的路线切换，不能把所有换乘都算作“小汽车—公共交通”的方式转换。

图1｜区域水深柱与红色阈值线决定哪些区域关闭；下方三层网络展示直接失效如何传递为线路失效，并改变通勤路径。原 Fig. 1a–f，正式发表版，出版社图1页面。这是机制示意，不是一次实测洪灾。

二、研究方法与关键机制

从日常出行建立受灾后的选择空间

南京模型把2019年的道路、公共交通网络与2020年的182,824个兴趣点结合，以1 km网格估计出行产生与吸引，再用修正重力模型生成工作日往返需求，剔除出行半径超过20 km的行程。公交线路映射到道路上，使公交与小汽车能够共享道路并相互影响。汉堡和洛杉矶采用已有开放仿真情景，分别模拟25%和10%的人口，容量随抽样比例缩放；南京使用其生成需求的100%，不等于模拟全体南京居民（补充 Notes 2–4、6）。

MATSim反复进行“加载出行计划—计算效用—重新规划”：活动时间带来正效用，旅行时间、费用和换乘带来负效用，个体调整路线、方式及出发时间，直到效用和方式份额近似稳定。南京初始出发时间按小时分布抽样，调整范围为正负30分钟。这里形成的是反复优化后的近似均衡，并非证明灾民在突发洪水中能即时找到同样方案（补充 Notes 3–4）。

洪水耐受阈值与真正的功能损失

研究采用百年一遇洪水图。南京、汉堡使用河流洪水数据，洛杉矶使用包含当地多种洪水风险的数据。模型以区域水深是否超过阈值 TTT 判断关闭；TTT 越大，代表综合防护、排水和车辆耐受能力越强，同一洪水图下的直接失效越少。它不是实时河道水位，也不是允许小汽车驶入数米积水的安全指标（补充 Note 7）。

三、主要结果与证据

结构断裂与功能下降不在同一个阈值发生

南京小汽车网络在 TTT 从5.8 m降至5.6 m时出现大范围间接失效，但图2g中的可行行程在 T=3T=3T=3 m仍约为基线的56%，到2 m才接近零。剩余道路数量和乘客能否完成行程之间，存在需求位置、替代方式与拥堵的共同作用，不能直接换算。

汉堡在1.8–1.6 m附近出现最大连通分量的位置切换，公共交通与小汽车承担的出行明显重排。图2j中水退后功能短暂下降，补充 Note 8.3将其归因于最大连通分量转移到需求较少的区域。这个非单调现象依赖模型的连通分量处理，不能直接解释为真实城市中退水会损害交通。洛杉矶的总可行行程曲线则几乎与汽车贡献重合，反映其汽车主导的需求结构。

四、意义与适用边界

本研究最有价值的认识是：交通韧性取决于替代网络是否仍可用、需求能否转移，以及转移后容量能否承受。修复连通性与增加行为选择都可能有益，但保住一条可用的公交—地铁链条，和让所有人各自找到可开车路线，产生的集体结果可能完全不同。

实证约束需要分层理解。南京平均出行时间由实测38分钟校准到36.16分钟，公共交通份额由62.5%校准到60.91%，四项校准指标相对误差绝对值均小于5%（补表6）。这说明基线统计得到匹配，不等于极端洪灾预测误差小于5%。洪水检验使用普通暴雨工作日代替百年一遇事件；洛杉矶检验的是出行半径而非旅行时间。补图5中南京两种情景的KS距离为0.252和0.226，均标注 p<0.001p<0.001p<0.001；小 ppp 值不能作为两个分布一致的证据。补图6的洛杉矶距离较小，但仍不能据此验证极端洪灾中的全部行为机制。

跨城比较还同时改变了洪水类型、地图分辨率、网络和需求：南京、汉堡洪水数据为1 km级，洛杉矶为地块级。三城差异不能单独归因于居民偏好或公共交通建设。5小时不可接受阈值、区域统一关闭规则、近似均衡以及每天退水1 m，都是结论的具体条件；补充 Note 7.5虽检查了分交通方式的异质阈值，也没有消除全部情景依赖。

补充 Note 12报告洛杉矶不同收入、族裔和教育群体的适应能力差异，但对应扩展图图像及指标完整定义缺失，因此只能确认作者进行了这项分组分析，不能据此给出精确差距或社会属性的因果解释。补充 Note 13与补图33只模拟了给公交和应急车辆保留车道对常规需求的影响，没有实际加载疏散车辆，不能推演完整救援效率。现有证据支持的是三座城市、指定需求和洪水情景中的适应机制及其条件，而非所有城市或其他基础设施系统的普遍定律。
