Slotte et al. - Herring spawned poleward following fishery-induced collective memory loss

鲱鱼产卵区北移：年龄选择性捕捞如何可能打断迁徙路线的代际传承

Nature，642：965–972（2025）。DOI：10.1038/s41586-025-08983-3

一、研究问题

挪威春季产卵鲱鱼长期从北方越冬区南下，在挪威西海岸的 Møre 一带产卵。然而，2021–2024年的主要产卵区转向 Lofoten，向北移动约800公里。论文要解释的是：一条维持数十年的迁徙路线，为何会在很短时间内被另一条路线取代？作者提出，年龄选择性捕捞削弱了掌握传统路线的老鱼群体；当数量庞大的2016年出生世代加入成鱼群体时，代际接触不足，使传统路线未能有效传下去。（图1a、图2a、图3）

南迁原本是一种有成本的繁殖策略。由最东北端越冬区到 Møre 南端，沿陆架的路程可达约1,300公里；成鱼逆着沿岸流游动，消耗储备能量，但后代可以在较南方较暖、饵料条件较好的水域开始生长，再随海流北漂至育幼区。因而，“少游一些”未必意味着繁殖收益更高。真正需要检验的是，北方产卵究竟由游泳能力或环境变化直接决定，还是因为鱼群失去了继续采用旧路线的社会条件。（引言，期刊第965页；“Influence of migration constraints”，第969页）

这里的“集体记忆”，指通过有经验个体与初次繁殖个体共同迁徙而维持的路线传统。“丧失”可以表现为知道旧路线的鱼数量减少、不能与新鱼充分混群，并不要求存活老鱼本身遗忘。论文的贡献，是将产卵区变化、世代更替和接触机会连成一条可检验的解释链；社会学习过程本身仍是由这些证据推断出来的机制。（“Why memory loss could explain the shift”，第966–967页）

二、研究方法与关键机制

从种群分布追到鱼群组成

研究首先整合挪威、冰岛和法罗群岛的渔获记录，覆盖1995–2023年约80%的总上岸量，再用科学调查核对空间变化。关键的产卵期声学拖网调查在2018–2024年采用可比较的设计，于2月14–25日间用约10天覆盖产卵分布区，估计各空间分区的鱼量和世代组成。这一步很关键：渔获地图同时受鱼在哪里、渔船在哪里作业影响，不能单凭捕捞活动北移认定鱼群北移。图1e甚至特别指出，2011年后摄食季渔获变化部分反映配额下降后的捕捞策略。（Methods：“Catch data”“Spatiotemporal cohort data”，PDF第9页；图1e、图3b）

作者随后将单次拖网或围网捕获样本作为鱼群年龄结构的代理。2017–2024年共有3,226份作业样本，分析其中91,878尾2016年及更早出生、完成年龄鉴定的鱼。对每份样本，用 N2016N_{2016}N2016​ 表示2016年世代的尾数，用 N<2016N_{<2016}N<2016​ 表示更老世代的尾数，则其相对数量为：

p2016=N2016N2016+N<2016. p_{2016}=\frac{N_{2016}}{N_{2016}+N_{<2016}}. p2016​=N2016​+N<2016​N2016​​.

分母不含2016年以后出生的鱼，因此它不是该世代占所有年龄鱼的比例。以下是帮助理解的演示，非论文观测：两个各50尾、仅含2016年及更老世代的鱼群，分别有45尾、15尾2016年世代鱼，其比例为 45/50=0.9045/50=0.9045/50=0.90 和 15/50=0.3015/50=0.3015/50=0.30；合并后却只有 60/100=0.6060/100=0.6060/100=0.60。同一个总体比例，可以掩盖极不相同的代际接触机会。这正是作者按季节、地点画出每份样本组成，而不满足于总体年龄比例的原因。图中的0.5表示数量过半，不是已经测得的文化传递临界点。（图3a；Methods，PDF第9页）

将“游不到”与“没有继续南游”分开

生物能量模型检验的是：即使鱼愿意沿传统方向前进，身体和海流是否允许？模型使用2016年世代在2020–2023年的体长、体重，以及沿途海流，模拟各年份平均体型的代表鱼沿13段预定路线的消耗。鱼在产卵迁徙中不摄食；模型设净前进速度为每秒一个体长，逆流越强，维持该速度所需的实际游速和耗能越高，同时还需给性腺发育分配能量。（图5；Methods：“Bioenergetic migration model”，PDF第10–11页）

判断剩余储备是否足够时，作者采用 Fulton 肥满度。令 WWW 为总湿重、GGG 为性腺湿重，单位均为克，LLL 为厘米计的体长；扣除性腺后的 CF∗CF^*CF∗ 表示产卵后状态：

CF=100WL3,CF∗=100W−GL3. CF=100\frac{W}{L^3},\qquad CF^*=100\frac{W-G}{L^3}. CF=100L3W​,CF∗=100L3W−G​.

演示算例，非论文数据：一尾30厘米、总重189克、性腺重27克的鱼，L3=27,000L^3=27,000L3=27,000，所以 CF=18,900/27,000=0.70CF=18,900/27,000=0.70CF=18,900/27,000=0.70；产卵后余162克，CF∗=16,200/27,000=0.60CF^*=16,200/27,000=0.60CF∗=16,200/27,000=0.60，恰好达到模型的停止南迁条件。

这个0.60来自1935–2023年26,452尾体长至少27厘米、已产卵鲱鱼的第10百分位。它是作者据此设定的风险界限，并非经死亡实验确定的绝对生理极限；肥满度也只是能量状态的代理。模型因此回答的是给定条件下的迁移潜力，不会自行生成社会学习或路线记忆。（Methods，PDF第11页）

三、主要结果与证据

北移与老世代衰退发生在同一阶段

图2a显示，2月下半月渔获纬度重心在多年相对稳定后快速北移；图3b的声学调查进一步显示，2021年以后主要鱼量集中到北方，2016年世代、较老世代及后续世代均出现在新的产卵分布中。约800公里指主要产卵区域从 Møre 到 Lofoten 的变化，不能解读为每尾鱼都移动了同样距离，也不是完全停止在其他地点产卵。（图1a、图2a、图3b）

标记重捕提供了另一层支持。2016–2023年在东北部沿岸越冬区标记202,155尾鱼；2018–2024年扫描约220万吨渔获，获得10,716次重捕，2024年的记录仅覆盖第一季度。到2020年，重捕分布仍包括向西摄食、外海越冬和向 Møre 南迁；2021–2024年则明显与北方产卵分布一致。PIT标签在加工厂检出，记录的是捕获终点，并非连续轨迹；图4的重捕地图也合并展示不同标记年份和世代，因此不能据此声称追踪到了同一尾老鱼逐年改走路线。（图4；Methods：“Tag-recapture data”，PDF第10页）

与此同时，年龄结构剧烈改变。作者报告2017–2022年捕捞量较建议配额超出约40%，且捕捞死亡率随年龄增加。2019–2023年，早于2016年出生的繁殖鱼生物量从约400万吨降至130万吨，下降约68%；2016年世代的补充却让总繁殖生物量仍略高于预防性参考水平。由此可见，总鱼量尚能维持与老世代持续减少可以同时发生。论文并未把这一降幅全部分解为捕捞的因果效应，但年龄选择性捕捞为老鱼减少提供了明确的人为压力。（图2c–g；“Disrupted migration linked to fishing”，第966页）

图2｜北移发生在老世代衰退与强势世代补充交叠时。 先看a中随年份变化的渔获纬度重心，再对照c的繁殖生物量（百万吨）：总量黑线与早于2016年出生世代的蓝线分开，显示老鱼减少可被新世代补充掩盖。c的红、绿线是1999、2009年的旧评估，并非不同鱼群。d对比实际捕捞量（黑）与建议配额（红），单位也是百万吨；e比较按尾数加权（黑）与未加权（红）的成鱼平均捕捞死亡率 FFF；f按年龄展开，显示较老鱼承受较高捕捞压力，黑点标出2016年世代。g比较渔获与春季、夏季、产卵期调查中的2016年世代比例。b按出生世代比较4龄鱼在至少4龄鱼中的比例，h、i分别呈现7龄鱼体长（厘米）与产卵前肥满度。b、g的虚线表示比例0.5，c、e的虚线为预防性参考水平；c、e灰带为评估值的95%不确定性范围，h、i灰带为均值的95%置信区间。全图支持北移与年龄结构更替相伴的判断，尚未将这些关系分解为独立的因果效应。

两个强势世代的早期混群差异

2016年世代开始加入成鱼群体时，老鱼主要在更西南方摄食和越冬，双方并未均匀混合。2016年世代是12年来首个强势世代，作者认为其与存留老鱼较大的年龄、体型差距，加剧了迁徙范围的分离。2020年，该世代中开始产卵的鱼由东北部越冬区到 Lofoten；之后随着体型增大，它们的摄食分布逐渐向西扩展，产卵地点却持续留在北方。较老世代的产卵分布也随之北移，后续年轻世代同样进入新分布。作者据此提出，早期接触不足让新世代先形成了自己的路线，等到充分混群时，迁徙传统的传递方向已可能反转。（图3a、b；扩展数据图1、2；第967–968页）

图3｜早期分离与后来的共同北方产卵。 a的每列从上一年Q2、Q3、Q4读到下一年Q1，覆盖摄食、越冬至产卵的年度循环。每个点代表一次作业样本，颜色表示2016年世代占该世代及更老鱼的比例：紫色为0，黄色超过0.75，其间各色表示不同混合比例；分母不含更年轻的鱼。早期东北方的高比例样本与西南方老鱼占优的样本分离，随后2016年世代向西扩展摄食分布，产卵季却持续偏北。b用2018–2024年2月声学调查核对产卵分布：圆饼位于空间分区中点，大小表示相对鱼量，蓝、黄、绿分别为早于2016年、2016年及更晚出生的鱼。原图图注称圆饼按全研究期最大估计值缩放，Methods（PDF第10页）则称按各年最大值缩放，因此不据圆饼大小比较跨年鱼量。各年内部的南北分布和世代构成显示，北方鱼群同时包含老鱼与新鱼，支持多世代产卵分布共同北移。图中没有显示估计误差，也未直接记录个体间的跟随或学习行为。

原文图3a、b；出版社正式版（publisher PDF），原始PDF第4页，期刊第968页。来源：论文PDF。

2002年世代构成重要的历史参照：它也数量庞大，曾在类似纬度越冬，老世代同样受到捕捞削减，却最终沿袭南迁路线。它与当时占优势的1998、1999年世代年龄和体型更接近。扩展数据图3显示其补充早期就与老鱼在不同季节发生空间混合；扩展数据图4显示，2005–2007年随体型增长，该世代在南部产卵鱼中的比例逐渐增加，同一年到达南方的个体通常更大。作者解释，较快生长的鱼可能先跟随老鱼南下，随后再成为同世代较慢生长个体的路线示范者。（扩展数据图3、4；第969页）

扩展数据图3｜强势世代补充仍可伴随南迁路线的延续。 读法与图3a相同，每列从Q2读至翌年Q1；这里的点色改为2002年世代占该世代及更老鱼的比例，紫色为0，黄色超过0.75，中间颜色表示样本中同时存在新老世代。关注2004–2005至2006–2007三列：摄食、越冬和产卵季较早就出现混合样本，随后Q1在较南纬度也出现更高的2002年世代比例。点色表示组成，不表示鱼量或个体轨迹，图中未给出误差条。这一历史参照支持早期混群机会对路线延续的重要性，但并不是控制环境等条件后的实验比较。

原文扩展数据图3，完整图，无字母子图编号；出版社正式版（publisher PDF），原始PDF第15页。来源：论文PDF。

这一对照使机制比“数量超过一半便改道”更具体：路线延续需要有经验者存在，也需要新鱼在尚未形成稳定路线时接触它们。不过，这是不同时期的自然比较，未单独控制环境和其他世代差异；它支持混群机制的重要性，尚不能给出保存传统所需的老鱼最低比例。

身体约束能解释起点，难以单独解释持续性

模型预测2020年首次产卵时，体型较小和较强逆流使2016年世代停留在 Lofoten 附近，这与观测一致。但2021–2023年鱼变大、海流较弱后，预测终点逐步向南，2023年更接近 Møre；实际产卵分布却持续偏北。关键是“有能力继续南游”与“实际没有恢复南迁”之间的分离。图5是给定参数下的模拟曲线，没有迁移终点的置信区间，其结果也没有证明2023年所有鱼都能游到传统产卵地。（图5a、e、f；第970页）

图5｜身体能力改善后，模型预期的南迁距离增加。 a标出各年的预测停止位置，红、绿、青、紫分别对应2020–2023年；b以箭头展示2020年表层流场。c–f的横轴均为由北向南的13段路线编号，纵轴依次为总湿重（克）、累计能耗百分比、产卵后肥满度和实际游速（体长/秒）。f的游速用于抵消海流影响，使净前进速度保持每秒一个体长。读图的关键是e的曲线何时降至0.60虚线：这一模型停止条件决定a的位置；c–f仍绘出沿完整路线的假设计算，越过停止条件后的部分不代表鱼实际继续迁徙。2020年的预测位置靠北，2023年则更接近 Møre，与图3b中实际产卵分布持续偏北形成对照。曲线没有误差带或终点置信区间，支持的是给定条件下迁移潜力改善，不能推出每尾鱼都能抵达南方产卵地。

原文图5a–f；出版社正式版（publisher PDF），原始PDF第6页，期刊第970页。来源：论文PDF。

历史身体状态提供旁证：7龄鱼体长分析包含第一季度采集的17,609尾鱼，2016年世代虽然小于某些历史世代，但与能南迁的2002年世代相近；36,501尾1月份体长至少27厘米、处于性成熟过程的鱼的肥满度资料，也未显示近期能量状态异常恶化。图2h、i的阴影是均值的95%置信区间，不能当作个体体长或体况的完整范围。（图2h、i；Methods，PDF第9页）

环境解释则通过1995–2024年三条浮游动物断面、三个温度站的时间序列检验。广义加性模型分别描述年份、季节及温度的深度效应，区分成鱼与卵所处的较深水层、仔鱼所处的浅水层。扩展数据图5呈现的温度和小型浮游动物生物量趋势，没有提供支持2020年后突然弃用南部产卵区的相应信号。浮游动物生物量是饵料可用性的代理，模型拟合显著也不等于已经检验了全部气候机制。（扩展数据图5–8；Methods：“Zooplankton biomass and temperature data”，PDF第11页）

作者仍保留一条间接气候路径：变暖可能延长西南方摄食机会，使老鱼更晚返回、就近越冬，减少与东北方新鱼的接触。这个解释把环境变化与社会传承联系起来，但其中的气候—饵料环节部分依据论文援引的既有研究，并非本研究直接操纵或单独识别的效应。（“Influence of climate change”，第970页）

四、意义与适用边界

这项研究最有分量的发现，是主要产卵区快速改变时，变化涉及多个世代，并且发生在强势新世代补充、老世代减少与早期空间分离叠加的阶段。综合这些证据，更有解释力的理解是：身体能力决定鱼能游多远，而鱼群组成和相遇机会可能决定一条可行路线能否继续被采用。持续的北方产卵及老世代分布随之改变，使“传统传递中断”超出了一个仅凭年轻鱼增多提出的猜想。（图2–5；扩展数据图3、4）

结论的力度仍应与观测设计相称。单次捕获样本代表鱼群组成是一项假设；没有直接记录谁跟随谁，也没有操纵老鱼比例来测定记忆阈值。标记重捕支持空间变化，能量与环境分析削弱了若干直接解释，它们共同支持作者的社会传承解释，却未将“捕捞导致记忆丧失”的各环节独立量化为因果效应。生物能量预测还依赖固定8°C、每秒一个体长的净速度、表层流代表实际遇流以及肥满度停止线等设定。（Methods，PDF第9–11页；Reporting Summary，第2–3页）

对管理而言，论文揭示了总生物量指标可能看不见的变化：补充量能够填补鱼量，却未必同步保住有经验世代及其与新鱼接触的条件。作者据此主张将社会学习纳入洄游鱼类管理，但尚未给出可直接执行的记忆阈值或配额规则。南部产卵减少还可能改变卵、仔鱼和能量对沿岸食物网的供给；本文没有量化由此造成的繁殖产量下降或海鸟损失，也明确承认北方产卵仍可能产生强势世代。其最稳固的结论，是迁徙传统可能随种群年龄结构与接触机会一起改变，而这些变化无法仅由鱼量是否充足来概括。（“Consequences for coastal ecology”“Consequences for management”，第970–971页）
