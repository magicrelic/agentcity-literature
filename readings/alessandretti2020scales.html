Alessandretti et al. - The scales of human mobility

人类移动的典型空间尺度，如何藏在看似无尺度的位移分布之中

一、研究问题

人们在日常语言中把活动空间分成建筑、街区、城市和地区：在街区买东西与跨城旅行，显然发生在不同层次。但把连续停留地点之间的位移长度汇总起来，许多既有研究又得到近似幂律的长尾，看起来没有一个主导距离。论文要解决的矛盾是：总体位移没有单一尺度，是否就意味着个人的活动空间没有层次、没有典型大小？（作者稿第2–3页）

作者的解释是，两者可以同时成立。人既在某个空间范围内反复活动，也偶尔跨出这个范围，进入更大的空间层级；把不同层级的移动混合统计，会掩盖各层自身的尺度。图1d用不同宽度的高斯分布展示了这种可能性：混合后的曲线在一段双对数区间近似直线。但这幅图只是数学示意，不能单独证明真实人类移动必由该机制产生。

因此，真正承担论证的是后续三步：从个人轨迹识别嵌套空间结构，检查同层结构是否具有典型大小，再用它生成未参与拟合的移动序列。如果只能把地图切成大小不同的区域，却不能解释人怎样在区域之间移动，就没有解决论文提出的问题。（作者稿第3–8页）

二、研究方法与关键机制

从停留地点到个人的空间层级

研究使用两组定位数据。作者稿将D1描述为从约500万人的记录中筛出约70万人，要求至少有一年数据，且每天至少一半时间的位置已知。正式Extended Data Fig. 1的说明则给出600,817人，并称对每人选取时间覆盖率中位数最高的一年；这与作者稿的约70万人不是同一个明确样本数，材料没有解释差别。D2包含851名丹麦技术大学学生。研究先用Infostop提取停留地点，默认空间参数均为30米、最短停留10分钟。因此，分析对象是停留地点间的转移，并非沿道路记录的每一步运动。（Methods，作者稿第12页；Extended Data Fig. 1及说明）

模型把每个人的地点组织成一棵嵌套结构：第1层是具体地点，更高层是包住若干地点的“容器”；每个容器完全属于一个上级容器。容器不是预先套入的行政区，各人的层数与边界分别拟合。一个地点可用从细到粗的容器序列表示。两地点的“层级距离”则是这两个序列发生差异的最高层号：同一容器里的地点切换，与跨越容器的移动，对应不同的层级距离。（作者稿第3–5、13–14页）

原图1b–d，作者稿v1，PDF第4页（来源）。b按颜色区分第2–5层，横轴分别为容器直径（米）和容器内停留时间（天），均为对数刻度；纵轴为原图标注的用户比例，虚线为中位数，时间列展示各人停留时间中位数的分布。c展示先选跨越层级、再逐层选目的地的过程。d为高斯分布混合示意，双对数图中的幂律虚线仅供比较斜率，不是实测轨迹的拟合结果。

一次移动为什么要分两步

第一步决定这次要跨越哪一层。这个概率还取决于当前位置离“家”有多远：人在外地时与在家附近时，跨越高层空间的倾向可能不同。模型中的家由各层吸引力最大的容器逐层确定，属于统计定义。第二步是在选定层级的其他容器中选目的地，再向下逐层选到具体地点。“吸引力”是同一父容器内的选择概率，并不直接表示就业机会或设施质量。（Methods，作者稿第13–15页）

用移动顺序挑选空间结构

容器的几何候选来自完全链接层次聚类：不断合并“合并后最大内部距离最小”的两簇，以保证空间紧凑。随后不是直接拿聚类树充当答案，而是寻找能够解释真实转移序列的树切分。给定结构HHH后，模型从转移频率估计概率矩阵ppp及吸引力集合aaa，再逐层尝试增加切分，用bootstrap评估似然改善。（Methods，作者稿第15–16页）

演示：一条轨迹只有两次转移，候选结构甲给出的概率为0.03和0.20，联合概率为0.006，对数似然约为−5.116；结构乙给出0.02和0.40，联合概率为0.008，对数似然约为−4.828，因此乙整体更能解释这段轨迹。第一步拟合更好，不保证整段序列拟合更好。

三、主要结果与证据

典型尺度存在，但个体差异仍然很大

真实轨迹呈现约四层结构，正式Extended Data Fig. 5中D1、D2的分布都在四层达到峰值；EPR在两层达到峰值，m-EPR几乎都为两层。作者稿及补充Note 4把EPR结果写成“一层”，与图中的层数标度不一致。可靠的对照方向是：真实轨迹的层级更深，识别程序并非对任何轨迹都会产生同样的多层结构。（作者稿第5页；补充PDF第7页；Extended Data Fig. 5及说明）

在D1中，第2–5层容器大小的对数正态拟合中位数依次约为3.1、27.1、88.4、161.6公里。这里的“大小”是容器内两地点之间的最大距离，既不是平均行程，也不是圆形活动区的半径。相应时间分布的图示中位数约为0.4、1.0、2.2、2.7天。正式Extended Data Table 1–2中，两个数据集第2–5层的容器大小及停留时间分布，相对截断幂律的似然比均支持对数正态，且达到0.01显著性水平。表内还列出D2的20、30、50米停留地点参数，支持这一比较在这些参数下保持方向；但对其他候选分布并非处处显著胜出，例如D2的若干log-logistic比较不显著，不能把对数正态说成唯一可能的分布。（图1b；作者稿第5–6页；补充PDF第3页；Extended Data Fig. 2、Table 1–3）

“有尺度”不等于“高度一致”。正文及Extended Data Table 3给出的大小分布变异系数为2.721–3.042，意味着标准差约是均值的三倍；典型尺度与显著个体差异并存。中位数的中心值相符，但第3–5层的“±”量在正式表中分别为58、217、498米，作者稿写成6、22、49米，不能混用这些不确定性。也不能把第2层一律命名为街区、第3层一律命名为城市：这些称呼帮助理解嵌套关系，实际层级来自每个人的轨迹。（作者稿第6页；Extended Data Table 3）

留出轨迹检验：优势不只体现在位移长尾

图2使用随机抽取的9,000人：每人用一年轨迹拟合模型，再生成1,000条各含50次位移的序列，与训练之后的50次真实位移比较。训练与检验在时间上分开，支持模型能重现后续短序列的统计特征，不能据此推出对任意未来时间跨度都没有过拟合。（作者稿第6–8页，图2图注）

原图2a–d，作者稿v1，PDF第7页（来源）。黑色为实测，橙色为容器模型，蓝色为EPR。a比较位移长度（米）的分布，c比较地点访问排名与访问频率，两图均为双对数坐标；b比较随位移次数变化的群体中位回转半径（米）；d比较时间熵减去无序熵的分布，负值表示地点顺序提供额外信息。原图注将a、c、d的模拟阴影定义为均值上下两个标准差，b为四分位区间；但d实际仅能辨认曲线，附带源数据也没有标准差列。这些区间不能统一解释成95%置信区间。

四项指标分别约束模型的不同方面。位移分布检查长短移动的比例；回转半径检查累计活动范围如何扩展；访问频率排名检查活动是否集中在少数地点；熵差检查模型是否保留地点出现的顺序结构，而不只是访问次数。容器模型在这些统计量上整体更接近实测。正文报告，对位移、访问频率和熵差分布的似然比比较均显著优于EPR。（作者稿第8页）

回转半径给出一个直观量级：图2b附带数据中，横轴49处实测值约7.08公里，容器模型约6.59公里，EPR约15.84公里。三者都可能呈现近似对数增长，却不能因此认为它们刻画了同样的活动范围。补充Note 4的对数拟合也显示，容器模型的增长参数更接近实测。（图2源数据，panel b；补充PDF第6–7页）

“更接近”仍然不等于重合。熵差图中，容器模型在远离零的负向尾部仍低于实测，说明这项顺序统计仍有偏差。补充比较还涉及m-EPR、d-EPR、DITRAS及recency-EPR。Note 4称D2未运行d-EPR与DITRAS，但正式Extended Data Fig. 4和Table 4恰在标为D2的部分给出两者结果，D1部分没有；材料不足以判定哪一处数据集标签有误。表4已列出的似然比均为正，但d-EPR的位移项仅标p≤0.05p\leq0.05p≤0.05，不足以支持Note 4所称所有比较均达到0.01水平。因此，多指标整体优势有依据，“所有模型、两套数据、同一显著性标准下全胜”则超出证据。（图2d；补充PDF第6页；Extended Data Fig. 4、Table 4及说明）

同一套尺度描述，如何呈现社会与环境差异

性别分析包括用户数超过1,000的53个国家。补充表S1显示，21国的男女层数分布通过KS差异检验；另一个有方向的Mann–Whitney检验显示44国女性层数倾向较多，没有国家显著呈现相反方向，均按表中p≤0.05p\leq0.05p≤0.05计数。正文将“21国”表述为女性层数更多，应与这两类检验区分。表S2另显示48国女性的第2层容器较小，不能扩大成所有层级都如此。（作者稿第9页；补充PDF第8–9页）

男女层数分布差异与国家性别不平等指数呈正相关，但强度存在来源差异：正文报告Spearman相关系数0.69，按图3b源数据中的50国配对值计算约为0.56。因此稳妥的结论是两者存在正向关联，而不是把某一个系数当作跨版本一致的常数，更不是性别不平等造成层级差异的因果证明。（作者稿第9页；图3b源数据）

四、意义与适用边界

论文的实质贡献，是把“位移分布长什么样”推进到“这些位移发生在怎样的个人空间结构中”。层级容器同时连接地理位置、转移频率与活动范围，并在留出序列中改善多项统计量。由此可以支持作者的核心解释：总体看似无尺度的移动，与具有典型大小的活动层级并不矛盾。

这一解释的力度也有明确边界。图1d说明分布混合能够产生近似幂律形态，图2说明容器模型具有解释力；两者共同提供一个可行机制，但没有排除所有其他生成机制。模型也未单独消融“对家距离的依赖”等组件，不能把整体优势全部归于某一项设计。

容器是从轨迹推断的统计结构。它可能与城市形态、交通条件和社会限制相联系，却不等于直接测得了人的心理地图或出行目的。研究中的性别、城乡及步行便利度结果提供了这种联系的观察证据，尚不足以确认改变环境便会如何改变个人移动。（作者稿第9–11页）

最后，模型主要解释已有地点之间的空间转移，作者明确没有纳入新地点探索、昼夜与周期访问规律、交通网络连通性。D1筛选后的高覆盖手机用户、D2的大学生样本，以及50次位移的验证范围，共同限定了现有证据。因而，这篇论文最有价值的结论是：汇总位移的长尾，并不能抹去个人活动空间内部有层次、有典型尺度的组织方式。（Discussion与Methods，作者稿第11–12页；图2）
