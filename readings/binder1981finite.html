Binder - Finite size scaling analysis of Ising model block distribution functions

有限尺寸下的序参量分布

Binder，Finite size scaling analysis of Ising model block distribution functions，Zeitschrift für Physik B Condensed Matter（1981）。原文。

研究问题

序参量分布及其矩如何随系统尺寸变化，并帮助识别临界行为？

方法、证据与解释

Binder 四阶累积量：分布形状随系统尺寸是否具有一致交点

常用非中心形式为

U4(L,u)=1−⟨m4⟩3⟨m2⟩2. U_4(L,u)=1-\frac{\langle m^4\rangle}{3\langle m^2\rangle^2}. U4​(L,u)=1−3⟨m2⟩2⟨m4⟩​.

也可明示采用中心版本 U4(c)=1−μ4/(3μ22)=1−K/3U_4^{(c)}=1-\mu_4/(3\mu_2^2)=1-K/3U4(c)​=1−μ4​/(3μ22​)=1−K/3，但两者不能混用。

  • 什么信号： 在适用的连续转变与尺寸标度假设下，不同 L 的 U₄(u) 曲线在临界控制量附近交汇；某些一阶转变可出现显著凹陷及分布共存。对非负拥堵份额，不能照搬对称磁化变量的“0/2⁄3”极限解释。
  • 需要： 多个可比系统尺寸、每一控制量上的大量近稳态样本、同一 m 定义；仅扩大轨迹抽样比例不是增加物理系统尺寸。
  • 来源与现实级别： Binder (1981), Finite size scaling analysis of Ising model block distribution functions, Z. Phys. B 43, 119–140，DOI 10.1007/BF01293604，元数据已核验。通用统计物理指标；纳入文献尚无可靠的真实城市/移动 Binder 应用，不能列成已被城市实证验证的常规指标。
