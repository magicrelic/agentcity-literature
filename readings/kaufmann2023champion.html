Kaufmann et al. - Champion-level drone racing using deep reinforcement learning

用实机误差校准仿真，让自主无人机在固定赛道达到冠军级竞速水平

一、研究问题

这篇论文要跨过的门槛，是让无人机一边依靠自身传感器判断位置与速度，一边逼近飞行性能极限，并在真实比赛中与顶尖人类竞争。高速穿门会放大两类误差：运动模糊使视觉定位漂移，真实气动力、控制器和电池响应又不完全符合仿真。规划出的路线越贴近极限，留给这些误差的余地就越小。论文指出，此前部分系统虽已接近专家水平，却依赖外部动作捕捉提供近乎完美的位置真值；这并未解决仅靠机载观测竞速的问题。（引言，刊页982，原PDF第1页）

Swift的核心回答是：把视觉与惯性信息整理为低维状态，以强化学习寻找控制策略，再用真实飞行中测出的感知和动力学误差修正训练环境。最终比赛中的无人机只依赖机载传感与计算，但准备阶段允许使用动作捕捉系统采集校准数据。这一区分决定了论文证明的是经过场地适配后的自主竞速能力。（The Swift system，原PDF第2–3页）

检验场景是一条由专业飞手设计、含7个方形门、单圈约75米的赛道，布置空间为30×30×8米。对手是两位国际赛事世界冠军Alex Vanover、Thomas Bitmatta，以及瑞士全国冠军Marvin Schaepper；三人获得一周练习时间。双方无人机的重量、外形和推进系统一致，每架870克，最大静推力约35牛。比赛要求按顺序完成三圈；若双方都无法继续，则按已完成赛程判胜。这使碰撞与持续完赛能力都成为成绩的一部分。（Fig. 1；Results，原PDF第1–3页；Methods“Drone hardware configuration”，第10页）

二、研究方法与关键机制

从图像到动作：保留可定位的中间状态

Swift没有让一个网络直接从像素预测电机指令。视觉惯性里程计（VIO）连续估计运动；门检测网络找出图像中的门角点，再结合已知赛道地图求得无人机位姿。高速飞行中的VIO位置会漂移，门则提供可反复识别的地标。具体实现中，卡尔曼滤波器估计位置漂移及其变化率，修正位置和速度；由于VIO姿态质量较好，滤波校正没有扩展到全部姿态分量。（Methods“VIO drift estimation”，原PDF第9页）

控制网络接收31维观测：位置、速度及旋转矩阵共15维，下一个门四个角点的相对位置共12维，再加前一步的4维动作。它输出单位质量总推力和三个机体角速度，交由底层Betaflight控制器转换成电机指令。策略是每层128单元的两隐藏层网络，以100 Hz运行；PPO训练时另有价值网络评估长期回报，价值网络可以读取仿真真值，但不上机部署。（Fig. 2；Methods“Policy training”，原PDF第8页）

把真实误差带进训练，而非只提高理想仿真的精度

仿真首先包含螺旋桨推力、气动效应、电机响应、底层控制和电池电压等模型。作者再让初始策略依靠动作捕捉真值完成三次真实飞行，约50秒，记录实际观测与预测之间的差异。这里的50秒是残差辨识数据量，不是整套系统从零建立所需的全部真实数据。（Methods“Quadrotor simulation”“Residual model identification”，原PDF第7–8页）

感知误差具有随机性，也会沿飞行过程持续演化。作者对位置、速度、姿态的九个分量分别拟合高斯过程，训练时抽取具有时间连续性的误差轨迹，而不是只给每一步添加互不相关的噪声。动力学偏差则被视为大体确定的修正，用k=5k=5k=5的近邻回归从状态和推力指令预测残差加速度，辨识样本约800–1,000个。Swift没有在训练中随机化平台动力学，而用这两种实测模型让策略经历接近实机的“看错”和“飞偏”，并学会在这些条件下完成任务。（Methods“Residual observation model”“Residual dynamics model”，原PDF第8–9页）

三、主要结果与证据

首先，仿真对照说明优势来自哪里。在理想动力学与真值观测下，预计算最优轨迹加MPC的最快无碰撞圈时为4.60秒，比Swift的4.88秒更快。加入从实机辨识的观测噪声或更逼真的动力学后，未经实机残差适配的基线均无法完成一圈；Swift在四种组合中都完成赛道：理想动力学下，真值与带噪观测的最快圈时分别为4.88、5.26秒；更真实的仿真动力学下分别为5.20、5.42秒。也就是说，论文的关键进展是让高速策略承受部署误差，而不是在完美模型里推翻最优控制。（Methods“Simulation results”，原PDF第9–10页；Extended Data Table 1c，第14页）

作者还把同一观测噪声模型的预测提供给基线。在理想动力学、带噪观测的条件下，零样本迁移、域随机化、最优轨迹加MPC三种基线的赛道完成比例分别为42%、19%、19%，Swift为100%。其中零样本迁移策略的最快有效圈时是4.92秒，比Swift的5.26秒短，却未完成整个赛程：单圈快与持续完赛是不同能力。表中百分数表示赛道完成程度，不是多次试验的成功概率；门余量的两个数表示平均值与最小值，也不是区间估计。作者说明，基线获得噪声模型的预测，Swift还考虑模型的不确定性，因此这也不是只替换控制算法的比较。这些对照支持经验残差适配的重要性，但没有分别移除感知奖励、门检测等全部模块，不能给每个模块单独分配胜负贡献。（Methods“Simulation results”，原PDF第9–10页；Extended Data Table 1b、c及表注，第14页）

其次，实机比赛直接支持“达到冠军水平”。Swift对Vanover赢5/9场，对Bitmatta赢4/7场，对Schaepper赢6/9场，合计15/25场，胜率60%。最快正式赛程为17.465秒，快于Vanover的17.956秒，差0.491秒。Swift输掉的10场中，4场因与对手相撞，4场因撞门，只有2场单纯因为更慢；速度优势并没有消除竞赛中的失败。（Fig. 3b；Results，原PDF第3–4页）

一周记录中的单圈中位数分别为5.52、5.76、5.96、6.80秒，Swift的分布也更集中。但这些记录混合了练习与竞赛，人类可以根据领先情况主动降速，Swift则不感知对手，始终追求最快预期完赛时间。因此，较窄的圈时分布体现了这个控制策略的一致性，不能单独证明它具有更强的对抗决策能力。（Fig. 3a；Results，原PDF第4页）

最后，轨迹分析解释了时间节省的具体位置。Swift平均提前约120毫秒起飞，并在紧弯采用更短路线。Split-S要求协调滚转与俯仰，完成下降半环并穿过两道门。最快三圈赛程的分段统计中，第1段仅在起步时经过一次，第2–4段各经过三次；按每次通过的平均值，Split-S所在第3段，Swift距离为26.89米、用时1.96秒，Vanover为28.91米、2.09秒；Swift平均速度反而略低，为13.70对13.86米/秒。它在这里主要通过少走2.02米赢得时间，而不是凭更高速度压过对手。与此同时，第4段Vanover的1.60秒略快于Swift的1.61秒，整体优势并不要求处处领先。（Fig. 4；Extended Data Table 1d，原PDF第5、14页）

四、意义与适用边界

这项工作的意义，在于把冠军级表现落实到了存在观测误差、气动偏差和碰撞风险的实体比赛。依据上述证据，更准确的理解是：学习策略、可解释的状态估计、物理仿真与实机残差校准共同构成了有效系统。受控比较支持的是这一组合在所测偏差下的适应能力，不能据此宣称强化学习普遍优于最优控制。

“冠军级”也有明确场景：固定且已知的赛道，允许赛前练习和实机辨识，面对三名冠军完成25场比赛。机器使用IMU并具有较低感知动作延迟，人类则有更高的视频刷新率，双方并非获得完全相同的信息。Swift依赖与训练时相近的环境外观，光照变化可能使感知失败；它没有接受撞机恢复训练，也不会根据领先或落后调整冒险程度。这些都是从本次成功迁移到其他竞赛条件时会直接改变表现的边界。（Discussion，原PDF第4页）

作者提出，更紧的转弯可能来自强化学习对较长时间尺度收益的优化；但轨迹本身只显示了动作与路径差异，没有直接测量人类或策略的规划跨度。本文最坚实的发现，是通过真实误差驱动的仿真适配，自主系统能在这一经过准备的高速竞赛环境中与顶尖人类竞争，并取得更快成绩；跨场地、外观变化和动态对抗能力仍不属于本次实验已经证明的范围。（Results与Discussion，原PDF第4页）
